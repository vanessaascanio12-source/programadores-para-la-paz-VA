Al ejecutar node server.js el servidor inicia correctamente y queda esperando solicitudes en el puerto 3000.

En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000".

Al visitar la ruta /estado se muestra una respuesta JSON indicando que el servidor está funcionando y que corresponde a una API comunitaria.

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
