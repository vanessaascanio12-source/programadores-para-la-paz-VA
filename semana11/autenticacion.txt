El login permite identificar a un usuario antes de darle acceso a ciertas funciones dentro de una aplicación.

Algunas rutas deben estar protegidas porque pueden contener información privada o permitir acciones importantes que no deben estar disponibles para cualquier persona.

No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni datos sensibles de la comunidad.

La autenticación ayuda a mejorar la seguridad y la privacidad de los usuarios.
