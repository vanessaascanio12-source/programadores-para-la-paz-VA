Al enviar una petición POST a la ruta /registro con los datos:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor responde:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto confirma que el servidor recibe correctamente los datos enviados por el usuario.
